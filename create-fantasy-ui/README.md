# Paquete visual Create: Pergamino de Latón

Paquete de recursos aparte de los cinco mods. Está planeado para Minecraft 1.21.1; actualmente no contiene texturas finales.

La dirección aprobada es pergamino medieval ilustrado con latón/casing cálido, engranajes, tornillería y palancas. El paquete podrá rediseñar el menú principal, botones y pantallas de configuración/lobby; será independiente y desactivable. Las texturas se dibujarán como arte original a mano/vector/pixel art, no mediante generación de imágenes. Se mantendrán fuentes editables y se revisarán licencias antes de usar cualquier referencia de terceros.

Las imágenes compartidas son referencias de estilo (una muestra de mapa con marca de agua); no se copiarán ni distribuirán dentro del pack.
