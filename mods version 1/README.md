# Mods versión 1 — descargas beta

**Todavía no hay JAR publicados.** No se colocan archivos vacíos ni compilaciones no probadas en esta carpeta. Cada JAR se añadirá aquí cuando exista una build real y pase las pruebas de carga descritas en [`../PLAN-MODS-VERSION-1.md`](../PLAN-MODS-VERSION-1.md).

La primera tanda prevista contiene cinco mods independientes para Minecraft 1.21.1 + NeoForge 21.1.267:

1. Registro de Hitos Industriales
2. Fábrica Viva
3. Desafíos de Expedición
4. Atlas de Frontera (estructuras y habitantes)
5. Cartografía Create: Pergamino de Latón (minimapa y atlas)

Cada publicación beta incluirá el número de versión, dependencias y lado requerido, changelog, instrucciones, pruebas ejecutadas y SHA-256. Solo se conservará un respaldo de la versión anterior por cada mod una vez que exista más de una versión.

Los mods externos del modpack no se redistribuyen aquí. La instancia debe instalar aparte las dependencias indicadas por cada beta.
